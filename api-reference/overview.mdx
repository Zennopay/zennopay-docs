Find endpoints for payment intents, beneficiaries, payouts, and payout
funding. All partner API routes use the `/v1` prefix.

<CodeGroup>
```bash Live
https://api.zennopay.com/v1
```

```bash Sandbox
https://api.sandbox.zennopay.com/v1
```
</CodeGroup>

See [Environments](/api-reference/environments) for alternate hosts and
isolation rules.

## Shared conventions

- HTTPS and UTF-8 JSON only.
- Server-to-server calls use [HMAC authentication](/authentication).
- Errors use `error.code` and `error.message`. Retain `error.request_id`
  when present; funding errors currently omit it.
- Store resource IDs and idempotency keys as opaque strings.
- Treat asynchronous resource reads as authoritative after network ambiguity.

## Money conventions

| Product | API representation |
|---|---|
| QR Payments | User authorization is integer `amount_usd_cents`; local minor-unit fields are int64 strings. |
| Platform Payouts | Every monetary field is a base-10 int64 string; VND has no decimal places. |

Never send a floating-point value for a Platform Payout or a local-currency
minor-unit field.
